# X (Twitter) login page clone

A front-end recreation of the X / Twitter login page, built to practise matching
a real, polished interface pixel for pixel.

## What it is

A static HTML/CSS/JS reproduction of the X sign-in screen — layout, styling and
interactions of the login flow, rebuilt from scratch as a UI exercise. It is a
visual clone for learning, not a working authentication system, and is not
affiliated with X.

## Repository layout

```
X Login Page Clone.html        the page
X Login Page Clone_files/       styles, scripts and assets it references
```

## Viewing it

Open `X Login Page Clone.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Built with

HTML, CSS and JavaScript.
